PDF & product glossary

Definitions for merge, split, OCR, eSign, Pdf Buddy, Kharch Log, KYC packs, and more — indexed for search.

  • Merge PDF — Combine two or more PDF files into a single document.
  • Split PDF — Divide a PDF into separate files or extract page ranges.
  • Compress PDF — Reduce PDF file size for email, WhatsApp, and upload portals.
  • OCR PDF — Optical character recognition that makes scanned PDFs searchable.
  • eSign PDF — Placing a drawn or uploaded signature on a PDF document.
  • PDF editor — Software to edit, annotate, organize, or convert PDF files.
  • Searchable PDF — A PDF with a text layer so you can find words with Ctrl+F.
  • PDF metadata — Title, author, subject, and keywords stored in PDF properties for discovery.
  • Unlock PDF — Remove a PDF password when you are authorized and know the password.
  • JPG to PDF — Convert image files into a PDF document.
  • Adobe Acrobat alternative — A PDF app that covers everyday edit/merge/sign tasks without Acrobat Pro pricing.
  • Desktop PDF editor — A Windows (or Mac) app that processes PDFs locally instead of in the browser.
  • Easy Peeze Tools — India-first product brand behind Pdf Buddy (Windows PDF editor) and Kharch Log (Android expense tracker).
  • Pdf Buddy — Desktop PDF editor for Windows by Easy Peeze Tools — merge, split, compress, sign, OCR, unlock, convert.
  • Kharch Log — Android expense tracker by Easy Peeze Tools with SMS auto-capture and Google Sheets sync.
  • KYC PDF pack — A single PDF combining photo, ID, address proof, and signature pages for portal uploads.
  • UPI expense tracker — An app that turns UPI debit SMS into logged expenses — Kharch Log’s core workflow.
  • Local-first PDF — Processing PDFs on your device instead of uploading them to a cloud editor.
  • PDF whiteout — Covering part of a PDF with a white rectangle. Hides pixels but is not forensic redaction.
  • Form 16 PDF — Employer-issued tax certificate PDF often split, compressed, or merged for ITR / loan packs.
