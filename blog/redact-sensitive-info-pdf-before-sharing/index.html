Cover sensitive lines on a PDF before you share it

2026-09-13 - PDF privacy, edit PDF, Aadhaar

KYC and office workflows often need a PDF - not the whole identity dump. Cover what the recipient does not need.

Before you send

  • Aadhaar: mask middle digits when a full number is not required
  • Bank PDF: hide account number / IFSC if the ask is only "address proof"
  • Salary slip: hide unrelated deductions if HR only needs gross / net

Do it on the PC

Use Edit PDF locally (white boxes / overlays), save a copy, and keep the original locked away. Then compress if WhatsApp complains. Related: password-protect before email.
