Page numbers and order: finish a portal pack in a Pdf Editor

2026-09-18 - Pdf Editor, merge PDF, split PDF, KYC PDF pack, India portals

A "complete PDF" that starts with a blank camera page, then marksheet, then photo, will still fail a fussy portal. The last 10 minutes in a Pdf Editor are page order, not another compress pass.

Order before size

  1. Split out blank or duplicate scans.
  2. Merge in the portal's listed order (photo, ID, address, signature).
  3. Rotate sideways phone pages. See rotate PDF.
  4. Only then compress.

Filenames portals actually open

Use ASCII hyphens: kyc-firstname-lastname.pdf. Avoid spaces and emoji. Put the human title in PDF properties if you care about search; details in PDF metadata.
